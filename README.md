# Medical Insurance Charges Prediction

A FastAPI web application that predicts medical insurance charges using a Linear Regression model.

## Project Structure

```
├── app.py                  # FastAPI app (routes + prediction)
├── train_model.py          # Train model & save pickle + JSON
├── medical_insurance.csv   # Training dataset
├── Linear_Model.pkl        # Pre-trained model (generated by train_model.py)
├── project_data.json       # Model metadata (generated by train_model.py)
├── requirements.txt        # Python dependencies
├── Dockerfile              # Build container image
├── templates/index.html    # Form + result page
├── static/css/style.css    # Styling
├── .gitignore
└── README.md
```

## Technologies Used

- Python
- FastAPI
- Uvicorn
- Scikit-learn
- Pandas
- NumPy
- Jinja2

## Local Setup

```bash
# Create virtual environment
python -m venv venv

# Activate the environment
venv\Scripts\activate          # Windows
# source venv/bin/activate      # Linux / macOS

# Install dependencies
pip install -r requirements.txt

# Train the model (generates Linear_Model.pkl and project_data.json)
python train_model.py

# Run the app locally
python app.py
```

Open the app in your browser at:

```text
http://localhost:8000
```

## Docker Setup

Build the Docker image:

```bash
docker build -t fastapi-insurance:latest .
```

Tag the image:

```bash
docker tag fastapi-insurance:latest mycr1211.azurecr.io/fastapi-insurance:latest


Run the container:

```bash
docker run --rm -p 8000:8000 --name fastapi-app fastapi-insurance:latest
```

Then open:

```text
http://localhost:8000
```

Stop the container:

```bash
docker stop fastapi-app
```

# Login to azure
az login --use-device-cod

## Push to Azure Container Registry

Authenticate to ACR:

```bash
az acr login --name mycr1211 -g myrg1         # myrg1  is nothing but resource group name  and mycr1211 is nothing but container registry name
```


## Push the image:

```bash
docker push mycr1211.azurecr.io/fastapi-insurance:latest
```
